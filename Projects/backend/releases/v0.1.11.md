## 1. TL;DR

New weather surface: OpenWeather 5-day/3-hour forecast, current weather, air
pollution, and an Open-Meteo marine lookup are now exposed under `/weather/*`.
The weather-map layer catalog is unified into one endpoint, and a fleet-wide
incremental-fetch fix stops datasources from silently missing records on cold
start and daily runs. Two new tables (`owm_forecast_records`,
`owm_air_pollution_records`) — see §6.

---

## 2. Highlights

### OpenWeather forecast + current weather + air pollution

- 5-day / 3-hour forecast, current conditions, and air-quality datasources with
  periodic pre-fetch pollers backing them.
- Where: `internal/datasource/open_weather_map/{forecast,current_weather,air_pollution}`, `internal/api/{currentweather,airpollution}`
- Surface: `GET /api/v1/weather/forecast`, `GET /api/v1/weather/current-weather`, `GET /api/v1/weather/air-pollution` (all by `lat/lng` or `state_province_id`)
- New config sections: `open_weather_map_forecast`, `air_pollution`, `current_weather` (enabled by default), all keyed off the OpenWeather API base + key.

### Open-Meteo marine lookup

- Point lookup for swell, ocean current, and sea-surface temperature.
- Where: `internal/datasource/marine_open_meteo/marine_forecast`
- Surface: `GET /api/v1/weather/global-marine` and `/weather/global-marine/lookup`
- Config: `marine_open_meteo` (disabled by default, `interval=10m`).

### Unified weather-map layer catalog

- v2 (OpenWeather Maps 2.0), v1, and self-generated GRIB2 layers now live in one
  catalog with source/tier tracking, so the FE discovers every tile layer from a
  single endpoint.
- Where: `internal/datasource/open_weather_map/weather_map`, `pkg/constants/constants.go`
- Surface: `GET /api/v1/weather/map/layers` now also lists GRIB2 layers (cloud
  ceiling, UV index, apparent temp, visibility); `HasForecast`/`MaxZoom`/tier
  metadata added per layer.

### Fleet-wide incremental-fetch correctness fix

- Datasources now advance on an event-date (or observation-date) watermark
  instead of fetch time, so records dated before the last run are no longer
  skipped — the root cause behind missing earthquake/conflict/drought records.
- Where: `usgs_earthquake`, `ucdp/conflict`, `usdm/drought`, `relief_web`,
  `nsidc_sii`, `noaa_gml`, `nasa_coolr/landslide`, `awdb/snow_cover`,
  `arcgis/chokepoints`.

## 3. Added

- **`open_weather_map/forecast`** — 5-day/3-hour forecast datasource, store, DTO, and `/weather/forecast` endpoint.
- **`open_weather_map/current_weather` + `api/currentweather`** — current weather by coordinates.
- **`open_weather_map/air_pollution` + `api/airpollution`** — current air quality with a periodic pre-fetch poller.
- **`marine_open_meteo/marine_forecast`** — marine (swell / ocean current / SST) point lookup.
- **`datasources`** — OWM forecast and air-pollution pre-fetch pollers wired into `internal/app/datasource.go`.

## 4. Changed

- **`weather_map`** — v2/v1/GRIB2 layers unified into a single catalog with source + tier tracking; `/weather/map/layers` now returns GRIB2 layers alongside OWM ones.
- **`weathertiles`** — cloud ceiling, UV index, apparent temp, and visibility exposed as GRIB2 tile layers and merged into the map-layers catalog.
- **`weather tiles`** — `MaxZoom`/`MinZoom` set to 1 for weather tile layers; layer definitions and legend object format updated.
- **`rapidapi/airport`** — aircraft filtering now accepts multiple selected types.
- **`newsdata/feed`** — news responses include a summary field.

---

## 5. Fixed

- **`usgs_earthquake`** — backfills are chunked to stay under USGS's 20k-event-per-query cap, so cold-start backfills no longer error out and drop events.
- **incremental fetch (fleet-wide)** — `ucdp/conflict`, `usdm/drought`, `relief_web`, `nsidc_sii`, `noaa_gml`, `nasa_coolr/landslide`, `awdb/snow_cover`, `arcgis/chokepoints` now watermark on event/observation date; late-dated records are no longer missed.
- **`usgs_earthquake`** — the incremental query window is now driven by the event-date watermark (`MAX("time")`) with a 30-day revision-lag overlap, not `MAX(fetched_at)`. Previously the USGS `starttime` bound tracked the ingest clock (≈ now), so earthquakes published with review lag and an older origin time were silently dropped after the first backfill. `MAX(fetched_at)` is now used only to throttle poll frequency.
- **`ucdp/conflict`** — pagination aborts on the first page error instead of committing a partial page as complete.
- **`solar_panel_output`** — upstream errors are mapped correctly instead of being swallowed.
- **swagger / legend** — swagger docs and legend object format corrected.

## 6. Migration notes

- **Database** — two new tables via golang-migrate: `owm_forecast_records`
  (`20260716000000_owm_forecast`) and `owm_air_pollution_records`
  (`20260716000001_owm_air_pollution`). Table names are `public.`-qualified.
  Confirm migrations run on deploy (`down` migrations ship for rollback).
- **Config / secrets** — new datasource sections require an OpenWeather API key:
  `open_weather_map_forecast`, `air_pollution`, `current_weather`
  (base URL `https://api.openweathermap.org/data/2.5`). `current_weather.enabled`
  defaults to `true` — set the key or disable it before deploy.
- **`marine_open_meteo`** — disabled by default (`enabled=false`); enable
  explicitly to turn on the marine lookup. No API key required.
- **API consumers** — `/weather/map/layers` payload now includes GRIB2 layers and
  new per-layer metadata (`source`, tier, `HasForecast`, `MaxZoom`); clients that
  hard-code the layer list should re-read from the endpoint.
