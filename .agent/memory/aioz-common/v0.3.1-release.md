v0.3.1 release note written 2026-09-11: `.gitlab/releases/v0.3.1.md` (repo) and `Projects/aioz-common/releases/v0.3.1.md` + `v0.3.1-review.md` (vault). It covers `6b79f13` (SSRF guard) and `5343511` (retry moved to caller-driven `Retry.Do`). Review verdict: **fix-first**. Findings: (1) `Retry.Do` checks `Idempotency-Key` only on attempt 0 while callers build the request per attempt, so a per-attempt key means a double POST; (2) the guard allowlist is not matched against NAT64/6to4-embedded IPv4 (fails closed); (3) a patch version for API removal.

**Tag gotcha:** `v0.3.0` is a *merge commit on main* (`1a6c26b`), not on the feature branch, so on `feat/http-postgres-retry` `git describe --tags --abbrev=0` returns `v0.2.0`. The real base is `git merge-base HEAD v0.3.0` = `119e779`. Use `v0.3.0..HEAD` (2 commits), not describe's answer (60 commits).

**Record fix:** `6b79f13` had written the SSRF guard into the CHANGELOG's v0.3.0 section and the vault v0.3.0 note after the tag was cut. Both were moved to v0.3.1, and the vault v0.3.0 note was restored byte-identical to the repo copy.
