The approved baseline is documented in `/home/tuan/personal/hospital/PROTOTYPE_SCOPE.md`.

The demo covers one focused appointment journey and one focused HomeCare journey, using a patient mobile application and hospital staff operations website with shared, simulated state. The interface is Vietnamese-first, Tam Anh-inspired, and designed for elderly and non-technical users.

Both journeys require full-fee payment through MoMo Test before confirmation. The selected slot is held for 10 minutes, IPN is authoritative, and failed, cancelled, or expired attempts release the slot. The demo has no refund flow.

**Why:** The user chose breadth across both product concepts while keeping each flow deep enough for an end-to-end interactive demonstration.

**How to apply:** Treat checked items as the baseline and unchecked items as optional until the user updates the checklist. A digital ticket or HomeCare assignment must not be created before verified payment. The archived plan is at `Projects/hospital/plans/2026-07-15-prototype-scope.md` in the Obsidian vault.
